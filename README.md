# 中国語学習アプリ

iPhoneで使えるPWA（ホーム画面へ追加できるWebアプリ）です。React・TypeScript・Viteで作成しています。

現在の試作品には、次の機能が入っています。

- 200語の初期単語データ（ピンイン・意味・ジャンル・品詞・例文付き）
- 単語とフレーズの登録・編集・削除・検索・絞り込み・並べ替え
- 中国語の自動ピンイン、繁体字から簡体字への変換提案、端末の音声読み上げ
- 朝10問・夜10問・無限列車編の4択クイズと習得度
- 学習カレンダー、JSON形式のバックアップと復元
- IndexedDBへの端末内保存、Service Workerによるオフライン対応

## 起動

```powershell
npm run dev
```

表示されたローカルURLをブラウザーで開きます。依存関係が既に入っている通常の利用では、再インストールは不要です。

## 品質確認

```powershell
npm run lint
node --test tests/core.test.mts tests/prototype.test.mts
npm run build
npm run preview
```

検証済みの詳しい内容と未実施項目は [試作品の実装・検証記録](./docs/prototype-status.md) を参照してください。

## iPhoneで使う前に

外部公開にはHTTPSのURLが必要です。`npm run build` でできる `dist` フォルダーを静的サイトの公開サービスへ配置し、iPhoneのSafariで開いて「共有」→「ホーム画面に追加」を選びます。

公開サービスのアカウント作成・規約同意・公開先の決定だけは本人操作が必要です。正式公開前には、仮のPWAアイコンを正式版へ差し替え、iPhone実機でインストール・オフライン起動・バックアップ復元を確認してください。
