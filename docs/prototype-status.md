# 03〜08 試作品の実装・検証記録

更新日: 2026-10-30

## 完成した範囲

### 単語帳

- 初回だけ200語を安全に登録します。既存の利用者データは消しません。
- すべての初期単語に、中国語、ピンイン、日本語、ジャンル、品詞、例文があります。
- 新規登録、編集、削除、重複確認、検索、ジャンル絞り込み、3種類の並べ替えに対応しています。
- 例文は複数登録でき、順番変更とフレーズ帳へのコピーができます。
- 入力中の中国語からピンインを自動生成し、繁体字を検出した場合は簡体字を提案します。

### フレーズ帳

- 登録、編集、削除、検索、ジャンル・お気に入り絞り込み、並べ替えに対応しています。
- 日本語は省略可能です。お気に入りと音声読み上げに対応しています。

### クイズと学習記録

- 朝の10問、夜の10問、回数制限のない「無限列車編」を用意しました。
- 日本語から中国語、中国語から日本語を各5問ずつ出題します。
- 同じ意味を持つ語が誤答候補に混ざらないようにし、可能な限り同ジャンルから選択肢を作ります。
- 正解で習得度を5増やし、不正解で5減らします（0〜100の範囲）。
- 日次クイズは10問完了時にまとめて保存し、無限列車編は1問ごとに保存します。
- 夜の問題は、朝に間違えた語を優先します。
- 月間カレンダーに日々の完了状況を表示します。

### 保存・PWA

- 学習データはIndexedDBへ保存します。
- JSONファイルとして全データを書き出し、内容を確認してから丸ごと復元できます。
- 15MBを超えるファイル、不正な形式、別アプリのファイルは拒否します。
- 本番ビルドでService WorkerとManifestを生成し、オフライン起動に必要なファイルをキャッシュします。
