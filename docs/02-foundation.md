## 共通データ契約

- 型：`src/core/model.ts`。`AppData.schemaVersion=1`。単語・フレーズ・順序付き例文・2方向暗記度・日付別完了・設定・初期化状態を含みます。例文の順序は配列順です。ピンインは`pinyinSource`で手動／自動を区別します。
- 保存：`src/core/storage.ts`。IndexedDBのDB名`ChineseLearningApp`、バージョン1、ストア`snapshots`、キー`app-v1`。PWAのCache Storageとは独立です。アプリ更新時に学習データを消す処理はありません。
- 読み込み：`await loadData()`。更新：`await transact(draft => { /* 同期処理 */ })`。複数レコードも1トランザクションで確定。戻り値が成功した後だけ画面に反映してください。コールバック内でawait／通信／音声などの副作用を実行しないでください。
- レコード更新はこのAPI経由で行います。DBが存在しない初回だけ空データを返します。不正データ・未知バージョン・保存失敗では既存データを初期化しません。復元UIは08で実装し、受信JSONは`assertData`を通し、さらに外部入力としての移行・関連整合性・サイズ制限を設計してください。
- `masteryKey(chinese)`は前後の空白とUnicode正規化のみ。繁簡変換や類義語の統合はしません。単語IDはカードごと、暗記度キーは同じ中国語表記ごと。初期0、2方向の平均を総合値とします。
- **編集・削除時の暗記度ルールは未決定**です。例：「學校」を「学校」へ編集したとき、既存の「学校」の暗記度とどう合流するか。03で実際に編集を実装する前に確認してください。現段階では暗記度レコードを自動削除・移行するAPIを作っていません。削除後も保持することで意図しない喪失を防ぎます。
- 「ジャンルなし」は空のgenresを拾う仮想フィルターとし、保存タグにしません。
- `installInitialWords`はデータセットIDで二重投入を防ぎます。正式200語は04が03の確定形式に合わせて作成します。異なるデータセット導入は移行手順なしに行えません。
- `completeDaily`は重複しない10語・前後5問の方向を検証し、暗記度と完了スタンプと朝誤答（方向付き）を一括更新。同じ開始日・モードの再送は無更新です。開始可能時間・出題・セッション開始日の固定は06の呼び出し側の責務です。日付は`localDate`で端末のローカル日付を使います。
- `applyInfiniteAnswer`は1回答ごとに更新。同一sessionIdとsequenceの再送は無加算、飛び番号は拒否します。sessionIdは起動後の新しいセッションにUUID、sequenceは1始まり。チェックポイントは重複防止メタデータのみで、未完了結果や回答履歴ではありません。将来増えるため08の移行時に整理方針を検討してください。
- クイズの途中回答・画面・検索語・結果はReactのメモリー上だけに置き、AppDataに追加しないでください。
- すべてのAppDataが将来のJSONバックアップ対象です。端末のブラウザー削除やストレージ消去には耐えません。現在はバックアップの画面なし。

## 共通の中国語入力・検索・音声

`components/ChineseInput.tsx`を単語・例文・フレーズで再利用できます。中国語欄からフォーカスが外れたときに声調記号付きピンインを生成。手動ピンインがある場合は上書き／維持を選択。繁体字→簡体字は提案し、明示的な承認時だけ本文を変更します。検索は声調と空白を無視し、üはuと区別、vとu:も受け付けます。フォーム保存時は未解決のピンイン選択が残らない設計を03で接続してください。

`core/language.ts`の`speakChinese`はボタン操作からのみ呼び出します。速度1／0.75は共通設定。中国語音声がない場合や再生エラーは日本語表示し、入力は保持します。

自動ピンインと字体変換はアプリに同梱し、外部APIに本文を送りません。多音字の完全な正確性は保証できず手動修正が必要です。無料の日本語訳自動生成は今回は導入していません。

変換処理は`core/conversion.ts`です。ピンイン検索用に内部で簡体字を使いますが、元の本文は変えません。辞書は入力コンポーネントと一緒に遅延読み込みします。

利用条件の出典：[pinyin-pro](https://github.com/zh-lx/pinyin-pro)（3.29.5、MIT）、[opencc-js](https://github.com/nk2028/opencc-js)（1.4.2、MIT AND Apache-2.0）。ライセンス本文と第三者表示は`docs/licenses/`へ保存しています。
